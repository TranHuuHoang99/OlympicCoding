Gọi f[i][totalLength][state]  : tổng giá trị tối đa khi có i phần tử đầu tiên, tổng số lượng phần tử = totalLength, state = 0, 1, 2, 3 hoặc 4 thể hiện phương án ta tính cho đoạn ta đang xét. 

Bài toán cơ sở: f[0][0][0] = 0 ,   khởi tạo các f[i][totalLength][state] còn lại = -inf 


đáp án bài toán: Max { f[n][k][state] }


công thức qhd: 

Khi ta có f[i][totalLength][state] != -inf 

Xét phần tử i + 1 


.  Ta có thể cho phần tử i + 1 là phần tử ở ngoài đoạn: 

   f[i + 1][totalLength][0] = max(f[i + 1][totalLength][0], f[i][totalLength][state]) 

.  Ta muốn i + 1 trong một đoạn mới 

   + Nếu i + 1 thuộc phương án 1 :   f[i + 1][totalLength + 1][1] = max (f[i + 1][totalLength + 1][1], f[i][totalLength][state] + 2 * v1[i + 1])

   + Nếu i + 1 thuộc phương án 4 :   f[i + 1][totalLength + 1][4] = max (f[i + 1][totalLength + 1][4], f[i][totalLength][state] + 2 * v4[i + 1])

   + Nếu i + 1 thuộc phương án 2 :   f[i + 1][totalLength + 1][2] = max (f[i + 1][totalLength + 1][2], f[i][totalLength][state])

   + Nếu i + 1 thuộc phương án 3 :   f[i + 1][totalLength + 1][3] = max (f[i + 1][totalLength + 1][3], f[i][totalLength][state])

.  Nếu state == 1

   f[i + 1][totalLength + 1][1] = max( f[i + 1][totalLength + 1][1], f[i][totalLength][state] + v1[i + 1] - v1[i])

   f[i + 1][totalLength + 1][2] = max( f[i + 1][totalLength + 1][2], f[i][totalLength][state] + v2[i] - v2[i + 1])

.  Nếu state == 4
