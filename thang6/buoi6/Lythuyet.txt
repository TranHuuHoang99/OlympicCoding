Two Arrays: 

Cho 2 dãy số a và c

Ta chọn một số x nào đó sao cho: 

Tổng c[i] * |a[i] - x|  với i: 1 -> n   nhỏ nhất có thể. 


Nhận xét: Nếu x <= a[i] =====> |a[i] - x| =  a[i] - x 

Nếu x >= a[i] =====> |a[i] - x| = x - a[i] 

Ta sắp xếp tăng dần theo a[i]  


Nếu ta có một số x 

a[i] <= x  <=   a[i + 1] 


=====> các số a[1], a[2], ....., a[i]  đều <= x ,    a[i + 1], a[i + 2], ....., a[n] đều >= x 


====> Tổng = c[1] * (x - a[1]) + c[2] * (x - a[2]) + ..... + c[i] * (x - a[i]) + c[i + 1] * (a[i + 1] - x) + c[i + 2] * (a[i + 2] - x) + ..... + c[n] * (a[n] - x) 



=  c[1] * x + c[2] * x + .... + c[i] * x - c[i + 1] * x - c[i + 2] * x - .... - c[n] * x - c[1] * a[1] - c[2] * a[2] - .... - c[i] * a[i] + c[i + 1] * a[i + 1] + ... + c[n] * a[n] 


=  x * (c[1] + c[2] + ... + c[i] - c[i + 1] - c[i + 2] - .... - c[n])  - c[1] * a[1] - c[2] * a[2] - .... - c[i] * a[i] + c[i + 1] * a[i + 1] + ... + c[n] * a[n] 

Xét đoạn [ a[i] ..... a[i + 1]    ]


Nếu c[1] + c[2] + ... + c[i] - c[i + 1] - c[i + 2] - .... - c[n] < 0 ====> x = a[i + 1] 

Nếu c[1] + c[2] + ... + c[i] - c[i + 1] - c[i + 2] - .... - c[n] > 0 ====> x = a[i] 



Sử dụng: 

prefixC[i] = c[1] + c[2] + .... + c[i] 
suffixC[i] = c[n] + c[n - 1] + .... + c[i] 

prefixAC[i] = a[1] * c[1] + a[2] * c[2] + .... + a[i] * c[i] 
suffixAC[i] = a[n] * c[n] + a[n - 1] * c[n - 1] + ..... + a[i] * c[i] 

=  x * (c[1] + c[2] + ... + c[i] - c[i + 1] - c[i + 2] - .... - c[n])  - c[1] * a[1] - c[2] * a[2] - .... - c[i] * a[i] + c[i + 1] * a[i + 1] + ... + c[n] * a[n] 

= x * (prefixC[i] - suffixC[i + 1]) - prefixAC[i] + suffixAC[i + 1] 



Xét x >= a[n]  hoặc  x <= a[1] 


Nếu x: a[n] ---> +oo 

Tổng = x * prefixC[n] - prefixAC[n] 


Nếu x: a[1] ---> -oo 

Tổng = x * (-suffixC[1]) + suffixAC[1]

Internet 

Ta có N máy tính và M đoạn dây mạng.

Đoạn dây mạng thứ i kết nối giữa 2 máy tính u[i] và v[i], chi phí của đoạn dây mạng là w[i] và đoạn dây mạng sẽ thuộc nhà mạng c[i] 

Ta cần chọn những đoạn dây mạng sao cho: 


Các máy tính trong toàn bộ N máy tính phải liên thông với nhau. 

Mỗi nhà mạng sẽ có chương trình khuyến mãi như sau: 

Nếu tổng chi phí ta sử dụng cho nhà mạng x mà > s[x] thì ta được giảm 50% 



Ví dụ 

s = 200000 


500000  

Họ sẽ giảm (300000) / 2 = 150000 ====> chi phí ta cần phải trả = 500000 - 150000 = 350000 


Hay nói cách khác: Nếu chi phí ta trả cho nhà mạng x là cost[x] =====> chi phí thực ta phải trả là: cost[x] - (max(0, cost[x] - s[x])) / 2 

Hãy tính chi phí tối thiểu là bao nhiêu ???? 



Nhận xét: 1 <= k <= 10 


Xét nhà mạng x: Giả sử được giảm giá ====> cost[x] >= s[x] 


cost[x] - (cost[x] - s[x]) / 2 = (cost[x] + s[x]) / 2 


====> chi phí sau khi giảm giá: cost[x] + s[x] 


Nếu giả sử không được giảm giá: 2 * cost[x] 


Giả sử ta có một tập hợp các nhà mạng x1, x2, ...., xk là những nhà mạng được giảm giá ====> những nhà mạng còn lại không được giảm giá

Xét nhà mạng thứ x, nếu có giảm giá: cost[x] + s[x]   (cost[x] < s[x] ===> cost[x] + cost[x])

.................., nếu không giảm giá: 2 * cost[x] 


Xét đoạn dây cáp nối 2 máy u và v với chi phí là w  (thuộc nhà mạng x) 

.  Nếu nhà mạng x có giảm giá: w 

.  Nếu nhà mạng x không giảm giá: 2 * w
