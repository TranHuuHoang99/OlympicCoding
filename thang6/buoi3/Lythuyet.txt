4 2 5 6 1 3

4 2 1 5 6 3

a[0] = -1 
a[n + 1] = -1 
Duyệt i: 1 -> n 
  nếu a[i] > a[i - 1] và a[i] > a[i + 1]: ans += a[i] 
  nếu a[i] < a[i - 1] và a[i] < a[i + 1]: ans -= a[i]

Khi ta có g nhóm 0 : a[1], a[2], a[3], ...., a[g] 

Số cặp (i, j) thỏa mãn: 


Tổng a[x] * a[y]  với x < y 



(a[1] + a[2] + a[3] + .... + a[g])^2 

= a[1]^2 + a[2]^2 + .... + a[g]^2 + 2 * ( Tổng a[x] * a[y]) 


Tổng (a[x] * a[y]) = [ VT - (a[1]^2 + a[2]^2 + ... + a[g]^2) ] / 2 


Bài toán đưa về: Trong tối đa k phép thay đổi, hay cho biết a[1]^2 + a[2]^2 + .... + a[g]^2 nhỏ nhất là bao nhiêu ?????? 


Gọi f[i][totalZero][numbSwaps] là tổng bình phương nhỏ nhất của các giá trị b[1], b[2], b[3], ....., b[i] sao cho: 

b[1] + b[2] + .... + b[i] = totalZero 


bài toán cơ sở: f[0][0][0] = 0,  khởi tạo các f[i][totalZero][numbSwaps] = inf 

đáp án bài toán: Max { (cnt0^2 - f[n][cnt0][numbSwaps]) / 2 } numbSwaps <= k  

công thức qhd: 


Khi ta có f[i][totalZero][numbSwaps] != inf 

Xét giá trị b[i + 1] 

Giả sử b[i + 1] = x   (x : 0 -> cnt0 - totalZero)

f[i + 1][totalZero + x][numbSwaps + |suma[i + 1] - totalZero - x|] = min( f[ ......],     f[i][totalZeros][numbSwaps] + x^2)
