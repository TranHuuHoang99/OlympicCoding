bài toán cơ sở: Xét một cạnh u - v: 

f[(1 << u) + (1 << v)][(1 << u) + (1 << v)] = 1

f[mask][submask] += f[mask - (1 << L)][submask - (1 << L)]

  nếu u thuộc mask 
    f[mask][submask] += f[mask - (1 << L)][submask - (1 << L) + (1 << u)]

Kỹ thuật S.O.S (Sum over subset) 


Cho danh sách các chi phí là cost[mask] : nếu tập hợp là mask thì giá trị là cost[mask] 

Với mỗi tập hợp mask, ta tính tổng tất cả các cost[submask] với submask là tập hợp con của mask  


cost [ {} ] = 2 
cost [ {0} ] = 10 
cost [ {1} ] = 8 
cost [ {2} ] = 15 


cost [ {0, 1} ] = 4 
cost [ {0, 2} ] = 12 
cost [ {1, 2} ] = 7 


cost [ {0, 1, 2} ] = 14 



mask = {0, 2} 

{}, {0}, {2}, {0, 2} : 2 + 10 + 15 + 12 = 39

Ta định nghĩa "bit linh động" là một bit i sao cho nếu nó "linh động", bit i = 1, có thể trở thành 0 hoặc vẫn = 1, nếu bit i = 0 thì bit i = 0 

Gọi f[mask][i] là tổng của các cost[mask] khi ta có i bit đầu tiên linh động 

bài toán cơ sở: 

f[mask][0] = cost[mask] 


công thức qhd: 

f[mask][i] = 

Nếu bit i = 1: f[mask][i] = f[mask][i - 1] + f[mask - (1 << i)][i] 

Nếu bit i = 0: f[mask][i] = f[mask][i - 1] 

Kết quả bài toán: 

Xuất ra các f[mask][N] 


f[mask][0] = cost[mask] 

for i: 1 -> N 
  for mask 
    f[mask][i] = f[mask][i - 1] 
    nếu bit i == 1: 
      f[mask][i] += f[mask - (1 << i)][i - 1]

Bit problem 

Với mỗi x, đếm số y sao cho x | y = x  ======> y là tập con của x 

Gọi f1[mask][i] là số lượng phần tử = mask nhưng có i bit linh động đầu tiên 

bài toán cơ sở: f1[a[i]][0]++ 

f1[mask][i] += f1[mask][i - 1] 
nếu bit i == 1 ===> f1[mask][i] += f1[mask - (1 << i)][i - 1] 



Với mỗi x, đếm số y sao cho x & y = x ======> x là tập con của y 


Gọi f2[mask][i] là số lượng phần tử = mask nhưng có i bit linh động đầu tiên 

bài toán cơ sở: f2[a[i]][0]++ 

f2[mask][i] += f2[mask][i - 1] 
nếu bit i == 0 ===> f2[mask][i] += f2[mask + (1 << i)][i - 1] 



Với mỗi x, đếm số y sao cho x & y khác 0 


Ta đưa về bài toán: Đếm số y sao cho x & y = 0 =====> ta lấy N - số lượng đó

====> kết quả: N - f1[(1 << 20) - 1 - x][20]
