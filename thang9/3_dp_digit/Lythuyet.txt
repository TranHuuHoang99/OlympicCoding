for i: 0 -> x 
  ways(x) += x! / i!  


ways(x) = x! * (1/0! + 1/1! + 1/2! + .... + 1/x!)

Gọi f[i][r][state] : số lượng số có i chữ số đầu tiên, tổng các chữ số đàu tiên chia D dư r cùng trạng thái state 

. state = 0: số này nhỏ hơn hẳn tiền tố độ dài i của số K 

. state = 1: số này bằng tiền tố độ dài i của số K 

. state = 2: số này lớn hơn hẳn tiền tố độ dài i của số K 

Bài toán cơ sở: 

Với chữ số đầu tiên là d (d: 1 -> 9)

Ta so sánh d với K[0] để ra state 

f[1][d % D][state]++ 

đáp án bài toán: 


Tổng các f[i][0][state] 


Nếu i < len(K) : state = 0, 1, 2 

Nếu i = len(K) : state = 0, 1 


công thức qhd: 

Khi ta có f[i][r][state] > 0 

Giả sử ta quyết định gắn chữ số d vào vị trí i + 1   (d : 0 -> 9) 

i ---> i + 1 
r ---> (r + d) % D 
state --> nextState 

Nếu state = 0 hoặc 2 =====> nextState = state 

Nếu d < K[i + 1] : nextState = 0 

Nếu d = K[i + 1] : nextState = 1 

nếu d > K[i + 1] : nextState = 2 


f[i + 1][(r + d) % D][nextState] += f[i][r][state]
