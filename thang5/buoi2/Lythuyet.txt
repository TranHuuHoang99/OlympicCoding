Distributing Apples 

Bài toán chia kẹo Euler: 

Có N viên kẹo, đếm số cách chia N viên kẹo cho K bạn, sao cho mỗi bạn phải có ít nhất 1 viên. 

====> số cách: C(K - 1, N - 1) 



Giả sử ta có N + K quả táo, ta đếm số cách chia N + K quả táo cho K đứa trẻ sao cho mỗi đứa có ít nhất 1 quả 


Ví dụ: 

N = 5, K = 3 



Ta có 8 quả táo 

[1, 2, 5]     ----->   [0, 1, 4]
[1, 1, 6]     ----->   [0, 0, 5] 
[6, 1, 1]     ----->   [5, 0, 0]
[2, 4, 2]     ----->   [1, 3, 1] 

..... 


C(K - 1, N + K - 1)

Planning The Trees 

Nhận xét: Ta hãy đếm số cách đặt N cây thỏa mãn và - cho số cách đặt cây mà chặn đường đi. 


[?, ?, ?, ?, ....., ?]

====> Số cách đặt cây = N! 


Số cách thỏa mãn = N! - số cách không thỏa mãn 


Số cách không thỏa mãn =

Giả sử ta đặt đường chéo có độ dài là i  (1 <= i < N )

Tổng các 2 * (N - i)!  với i: 1 -> N - 1     +   1     -    Tổng số cách mà ta "vô tình" chặn 2 đường chéo độ dài i và j 


Tổng số cách chặn 2 đường chéo = Tổng các (N - i - j)!   với mọi i + j <= N   (i >= 1, j >= 1 )



Ta gọi bảng fact[N] với ý nghĩa: fact[N] = N! 

fact[0] = 1 
for i: 1 -> 10^7 
  fact[i] = fact[i - 1] * i 


N! tương đương với fact[N] 


Tổng các 2 * (N - i)!  với i: 1 -> N - 1     +   1


i = 1 ====> (N - 1)! : fact[N - 1] 
i = 2 ====> (N - 2)! : fact[N - 2] 
.....

i = N - 1 ====> 1!   : fact[1] 


Đặt bảng sum_fact[i] = fact[0] + fact[1] + fact[2] + ..... + fact[i] 

sum_fact[i] = sum_fact[i - 1] + fact[i] 



2 *   (sum_fact[N - 1] - fact[0])   +   1 =  2 * sum_fact[N - 1] - 1 



Tổng (N - i - j)! 


j = 1 ===> Tổng (N - 1 - i)! = (N - 2)! + (N - 3)! + (N - 4)! + ..... + 0! = sum_fact[N - 2] 

j = 2 ===> Tổng (N - 2 - i)! = (N - 3)! + (N - 4)! + ..... + 0! = sum_fact[N - 3] 

.......

j = N - 1 ====> Tổng (1 - i)! = sum_fact[0] 


Đặt sum_sum_fact[i] = sum_fact[0] + sum_fact[1] + ..... + sum_fact[i] 

Tổng (N - i - j)! = sum_sum_fact[N - 2] 


Đọc số N:

Kết quả = fact[N] - ( 2 * sum_fact[N - 1] - 1 ) + sum_sum_fact[N - 2]
