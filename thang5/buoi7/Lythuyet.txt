Modulo Sum: 

Cho một dãy số nguyên dương a gồm N số. 

Cho một số nguyên dương K. Hay cho biết có thể chọn ra một vài số trong dãy a sao cho tổng các số trong dãy a có chia hết cho K 


1 <= N <= 1000000,

1 <= K <= 1000 




Gọi f[i][r][state] = true / false khi ta có i số đầu tiên của dãy a, tổng các số khi chia cho K dư r và trạng thái state 

. state = 0: ta chưa chọn bất kỳ số nào trong dãy 

. state = 1: ta đã chọn ít nhất 1 số trong dãy 


bài toán cơ sở: f[0][0][0] = true 

đáp án bài toán: f[n][0][1] == true ? YES : NO 


công thức qhd: 

Khi ta có f[i][r][state] == true 

Xét phần tử a[i + 1]  

. Ta không lấy a[i + 1] vào trong tập hợp: 

f[i + 1][r][state] = true 

. Ta lấy a[i + 1] vào trong tập hợp 

f[i + 1][(r + a[i + 1]) % K][1] = true

Mushroom Scientist: 

Cho một số S và 3 số nguyên không âm a, b, c 

Hãy xác định 3 giá trị thực không âm x, y, z sao cho: 

x + y + z <= S 

x^a * y^b * z^c lớn nhất 



Nhắc lại về bất đẳng thức trung bình cộng và trung bình nhân 

Xét N số thực không âm a1, a2, a3, ......, an 

(a1 + a2 + .... + an) / n  >= căn bậc n (a1 * a2 * a3 * ..... * an) 


Trường hợp để 2 vế = nhau: 

a1 = a2 = a3 = ...... = an 



x + y + z = x / a + x / a + ..... + x / a + y / b + y / b + ..... + y / b + z / c + z / c + .... + z / c   <=   S 



Áp dụng bdt trung bình cộng - trung bình nhân: 

(x / a + x / a + ..... + x / a + y / b + y / b + ..... + y / b + z / c + z / c + .... + z / c) / (a + b + c) >= căn bậc (a + b + c) ( (x / a)^a * (y / b)^b * (z / c)^c )



x^a * y^b * z^c = (a * x/a)^a  *  (b * y/b)^b   *  (c * z/c)^c = a^a * b^b * c^c * (x/a)^a * (y/b)^b * (z/c)^c = K * (x/a)^a * (y/b)^b * (z/c)^c 

Ta đặt K = a^a * b^b * c^c  


====> (x/a)^a * (y/b)^b * (z/c)^c = x^a * y^b * z^c  / K 


căn bậc (a + b + c) ( (x / a)^a * (y / b)^b * (z / c)^c )

= căn bậc (a + b + c) ( x^a * y^b * z^c  / K ) <= (x + y + z) / (a + b + c) <= S / (a + b + c)


Dấu "=" xảy ra khi ???? 

x/a = x/a = x/a = .... = y/b = y/b = ..... = z/c = z/c = ......  


x/a = y/b = z/c  = t 

x = t * a 
y = t * b 
z = t * c 

Để dấu "=" xảy ra thì x + y + z = S 

====> t * a + t * b + t * c = S ====> t = S / (a + b + c) 


x = S * a / (a + b + c) 
y = S * b / (a + b + c) 
z = S * c / (a + b + c)

AC6 (Autumn Contest 2021) 

Cho 2 số nguyên dương N và M 

Xét các số 0, M, 2M, 3M, ...., (N - 1) * M, với mỗi số này ta xét số dư khi chia cho N. Hãy cho biết các giá trị trên có khác nhau hay không ? 



Nếu gcd(N, M) = 1 ====> Xuất ra là CORRECT 


Phương pháp phản chứng 


Nếu gcd(N, M) = 1 =====> các số 0, M, 2M, 3M, ...., (N - 1) * M sẽ có các số dư khác nhau khi cùng chia cho số N 


Giả sử gcd(N, M) = 1 nhưng các số 0, M, 2M, 3M, ....., (N - 1) * M chưa chắc có các số dư khác nhau 


Giả sử 2 số có cùng số dư khi chia cho N là i * M và j * M   (giả sử i < j) 

====> j * M - i * M chia hết cho N 


(j - i) * M chia hết cho N 


vì gcd(N, M) = 1 

====> để (j - i) * M chia hết cho N thì j - i phải chia hết cho N 


j - i = N, 2N, 3N ......  vô lý 

vì j - i tối đa chỉ có N - 1
